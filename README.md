# Branca Fútbol Website

This repository used to be the website for Branca Fútbol.

It is now archived and no longer maintained.

It remains here as a snapshot of the club's old site structure, media, and content.

## Development

```bash
npm install
npm run dev
```

## Notes

- The site is built with Astro.
- Some content is static and some sections use lightweight client-side scripts.
- Media assets live in `public/images`.
